# 🔋 ECOSAVER – Smart Energy Management System

## 📌 Project Overview

ECOSAVER is a Smart Energy Management System built using Python, Streamlit, and MongoDB. It helps users monitor electricity consumption, analyze energy usage, and reduce energy costs.

## 🚀 Technologies Used

- Python
- Streamlit
- MongoDB
- Pandas
- PyMongo

## ✨ Features

- User Login & Registration
- Energy Dashboard
- Peak Usage Analysis
- Smart Scheduling
- Energy Forecasting

## ▶️ How to Run

```bash
git clone https://github.com/kodurupadmabindu/ECOSAVER.git
cd ECOSAVER
pip install -r requirements.txt
streamlit run app.py
```
